# APZ-Tool – Einfache Zusammenfassung von Stahl-Zertifikaten

**Willkommen!**  
Dieses kleine Programm hilft dir, Abnahmeprüfzeugnisse (APZ) von Stahlblechen schnell in eine übersichtliche Excel-Tabelle umzuwandeln.  
Du brauchst **keine Programmierkenntnisse** – nur Doppelklick und ein paar Mausklicks.

### Was macht das Tool?
- Du wählst PDF-Dateien mit Stahl-Zertifikaten aus (z. B. von Dillinger, voestalpine oder Ilsenburger).
- Das Tool liest die wichtigsten Daten automatisch aus.
- Es erstellt eine Excel-Datei mit einer klaren Tabelle.

### Neue Funktion: Spaltenauswahl
Im Programm siehst du jetzt eine Liste mit **Checkboxen**.  
Hier kannst du auswählen, welche Spalten in der Excel-Datei erscheinen sollen (z. B. nur WE-Nr., Schmelze, Material, t, Bemerkung usw.).  
Standardmäßig sind alle Spalten aktiviert. Du kannst Haken entfernen, wenn du bestimmte Informationen nicht brauchst.

### Download & Start (super einfach – keine Installation!)

1. **Herunterladen**:
   - Gehe auf: https://github.com/WojciechChomanski/APZ-Tool/releases
   - Lade die Datei `APZ-Tool.exe` herunter und speichere sie z. B. auf deinem Desktop.

2. **Starten**:
   - Doppelklick auf `APZ-Tool.exe`.
   - Ein Fenster öffnet sich.

**Tipp:** Rechtsklick auf die Datei → „Verknüpfung erstellen“ → auf den Desktop ziehen. Dann startest du das Tool immer mit einem Klick.

### So benutzt du das Tool

1. Fenster öffnet sich.
2. Klicke auf **„Dateien wählen (PDF/Excel)“**.
3. Wähle deine PDF-Zertifikate aus (mehrere mit Strg-Taste möglich).
4. **Optional:** Entferne Haken bei Spalten, die du nicht in der Excel haben möchtest.
5. Optional: Ändere den Namen der Ausgabedatei.
6. Klicke auf **„Start“**.
7. Warte kurz.
8. Fertig! Die Excel-Datei wird im selben Ordner gespeichert.

### Programm löschen (Deinstallieren)
Das Tool ist **portabel** – es installiert nichts.

- Einfach die Datei `APZ-Tool.exe` löschen.
- Fertig. Keine Spuren bleiben zurück.

### Probleme? Hier die häufigsten Lösungen

- Fenster öffnet sich nicht → Rechtsklick auf die .exe → „Als Administrator ausführen“.
- Antivirus meldet etwas → Tool zur Ausnahmeliste hinzufügen (es ist open-source und sicher).
- Fragen? Schreib mir gerne über GitHub (Issues).
